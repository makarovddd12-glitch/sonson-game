# Игровой дизайн (черновик)

## Жанр
2D run-and-gun с боковой прокруткой, вдохновлённый SonSon (1984).

## Управление (планируется)
| Действие | Игрок 1 | Игрок 2 |
|----------|---------|---------|
| Движение | WASD | Стрелки |
| Прыжок | Space | Enter |
| Стрельба | J | Numpad 0 |

## Основные механики
- Автоматическая прокрутка уровня вправо
- Стрельба по врагам
- Сбор предметов (очки, бонусы)
- Совместное прохождение на двоих

## Режимы
- **Co-op:** два игрока на одном экране
- **PvP:** (опционально) сражение друг с другом

## Цель игрока
Набрать максимум очков и пройти как можно дальше, не потеряв жизни.
