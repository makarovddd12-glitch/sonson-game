# SonSon — учебный проект по разработке игры

Учебный проект по созданию игры с режимом кооперативного прохождения
(и, при необходимости, PvP) на C# с использованием фреймворка MonoGame.

> **Статус:** репозиторий инициализирован, проект собирается и запускается.
> Игровая логика пока не реализована — ведётся проектирование и подготовка структуры.

---

## 📌 О проекте

Цель — реализовать игру в жанре 2D-экшен (run-and-gun), вдохновлённую
классической аркадой **SonSon** (Capcom, 1984), с поддержкой:

- локального кооператива на двоих;
- (опционально) режима PvP;
- базового геймплея: движение, стрельба, враги, сбор предметов.

Проект выполняется в рамках учебного задания. Основной упор — на чистую
архитектуру кода на C#, а не на использование готовых визуальных редакторов.

## 🚀 Сборка и запуск

### Требования

- [.NET SDK 8.0+](https://dotnet.microsoft.com/download)
- Шаблоны MonoGame:
  ```bash
  dotnet new install MonoGame.Templates.CSharp
  ```

### Запуск

```bash
# восстановить зависимости
dotnet restore

# собрать проект
dotnet build

# запустить игру
dotnet run
```

После запуска открывается окно MonoGame с базовым фоном — это подтверждает,
что проект настроен корректно.

## 🗂️ Структура репозитория

```
sonson-game/
├── Content/              # игровые ресурсы (спрайты, звуки, шрифты)
├── src/                  # исходный код (по мере разработки)
│   ├── Entities/         # игровые объекты: игрок, враги, снаряды
│   ├── Systems/          # системы: движение, бой, спавн
│   └── Scenes/           # сцены: меню, игра, PvP
├── docs/                 # документация
│   ├── plan.md           # план разработки
│   └── design.md         # черновик игрового дизайна
├── Game1.cs              # главный класс игры (пока шаблон)
├── Program.cs            # точка входа
├── SonSon.csproj         # файл проекта
├── .gitignore            # исключения для Git
└── README.md             # этот файл
```

> Папки `src/Entities`, `src/Systems`, `src/Scenes` и `docs/` создаются
> по мере разработки. Сейчас в них могут лежать `.gitkeep`.
